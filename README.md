# 🎮 The Street Kid 4X

An interactive 3D street adventure game focused on exploration, missions, and immersive gameplay.

## 📌 About the Project

**The Street Kid 4X** is a browser-based game project developed using JavaScript and modern web technologies. It includes 2D and 3D game implementations, scene management, player controls, city environments, mission systems, and sound management.

The project is designed to provide an engaging street adventure experience with interactive environments and scope for further gameplay improvements.

## ✨ Features

- 🎮 Interactive browser-based gameplay
- 🌆 3D city environment
- 🧍 Player movement and camera controls
- 🚗 Vehicle-related gameplay components
- 🎯 Mission management system
- 🔊 Sound management
- 🎨 Procedural texture generation
- 🕹️ Separate 2D game implementation
- 🧪 Test scripts for different development phases
- 🛠️ Vite-based development environment

## 🧰 Technologies Used

- **HTML5** – Game page structure
- **CSS3** – Styling and game interface
- **JavaScript** – Game logic and interactions
- **Phaser** – 2D game development
- **Three.js** – 3D graphics
- **Vite** – Development server and build tooling
- **Git and GitHub** – Version control and project hosting



## 🚀 Getting Started

### Prerequisites

Install the following:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- A modern web browser

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/Rakshay123/The-Street-Kid-4X.git
```

**2. Navigate to the project folder**

```bash
cd The-Street-Kid-4X
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the local URL**

Open the URL displayed in your terminal, usually:

```text
http://localhost:5173
```
